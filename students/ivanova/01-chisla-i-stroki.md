# Числа и строки

## Условие

Напишите функцию `stats(text)`, которая принимает строку и возвращает
кортеж из трёх чисел:

- количество символов (включая пробелы);
- количество слов;
- количество гласных букв.

Регистр не учитывать: считать и `А`, и `а`.

## Пример

```python
stats("Привет мир")
# (10, 2, 4)
```

## Что сдавать

Файл `stats.py` с функцией `stats`. В конце файла — несколько
примеров вызова в блоке `if __name__ == "__main__":`.
