# Срезы списков

## Условие

Дан список целых чисел. Напишите функцию `cut(numbers, k)`, которая
возвращает новый список: каждый элемент, взятый с шагом `k`, начиная
с первого.

Исходный список изменять нельзя.

## Пример

```python
cut([1, 2, 3, 4, 5, 6], 2)  # [1, 3, 5]
```

## Что сдавать

Файл `cut.py` с функцией `cut`.
