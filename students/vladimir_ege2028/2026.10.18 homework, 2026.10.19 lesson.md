### Пример 1

В начале программы созданы три переменные с начальными значениями:

```python
vozrast = 15
student = True
weekend = True
```

* `vozrast` — возраст зрителя, целое число;
* `student` — `True`, если зритель школьник, иначе `False`;
* `weekend` — `True`, если матч проходит в выходной день, иначе `False`.

На стадионе действуют два правила.

1. **Какой билет продать.** Льготный билет доступен школьникам и другим зрителям младше 18 лет. Во всех остальных случаях — обычный билет.
2. **Как пустить на матч.** По выходным для зрителей младше 14 лет вход разрешен только в сопровождении взрослого. Во всех остальных случаях зритель проходит самостоятельно.

Программа должна вывести две строки.

Первая строка: "льготный билет" или "обычный билет"

Вторая строка: "вход со взрослым" или "вход самостоятельно"

Программу нужно запускать с различными значениями переменных, чтобы убедиться, что она работает правильно во всех возможных сочетаниях условий.

**Решение**

```python
vozrast = 15
student = True
weekend = True

if student or vozrast < 18:
    print("льготный билет")
else:
    print("обычный билет")

if vozrast < 14 and weekend:
    print("вход со взрослым")
else:
    print("вход самостоятельно")
```

Вывод программы:

```text
льготный билет
вход самостоятельно
```

**Ответ:** Программа выводит две строки: первую про билет, вторую про вход. При начальных значениях из условия (vozrast = 15, student = True, weekend = True) ответ такой: 1. льготный билет 2. вход самостоятельно Первая проверка: льготный билет, если student равно True или возраст меньше 18. Иначе обычный билет. Вторая проверка: вход со взрослым, если одновременно возраст меньше 14 и weekend равно True. Иначе вход самостоятельный.
