### Пример 1

В начале программы созданы две переменные с начальными значениями:

```python
matematika = 3
russkiy = 5
```

* `matematika` — оценка по математике;
* `russkiy` — оценка по русскому языку.

Правила родителей:

1. Игра отменяется при плохих оценках по обоим предметам. То есть если и по математике, и по русскому оценка ниже 4. В ином случае игра разрешается.
2. Если игра разрешена и хотя бы одна оценка ниже 4, то обязательно нужно сначала сделать домашку по этому предмету. В других случаях домашка не нужна.

Программа должна вывести две строки.

Первая строка: "игра отменена" или "игра разрешена"

Вторая строка: "нужно сделать домашку" или "домашка не нужна"

Программу нужно запускать с различными значениями переменных, чтобы убедиться, что она работает правильно во всех возможных сочетаниях условий.

**Решение**

```python
matematika = 3
russkiy = 5

math_low = matematika < 4
rus_low = russkiy < 4

if math_low and rus_low:
    print("игра отменена")
else:
    print("игра разрешена")

if not (math_low and rus_low) and (math_low or rus_low):
    print("нужно сделать домашку")
else:
    print("домашка не нужна")
```

Вывод программы:

```text
игра разрешена
нужно сделать домашку
```

**Ответ:** игра разрешена нужно сделать домашку
