Известно:
- `est_akkayunt = True`
- `telefon_podtverzhden = False`

Создай переменную `mozhno_voyti`, которая будет `True` только тогда, когда выполнены оба условия.

Выведи `mozhno_voyti`.

**Решение**

```python

telefon_podtverzhden = False
mozhno_voyti = est_akkayunt and telefon_podtverzhden
print(mozhno_voyti)
```

Вывод программы:

```text
False
```

**Ответ:** False
